# Find that song

CS6750 individual project interaction prototype by Jason Tello.

A scripted voice conversation for finding a recently heard song without remembering its title or artist. Start the demonstration or explore the command buttons.

This is a design simulation, not a Siri or Spotify integration. No microphone or account connection is used. Listening history and song metadata are fictional. Original instrumental tones stand in for songs. Recorded dialogue uses ElevenLabs voices. The wallpaper is an original recreation. Test while stationary.

## Run locally

Run `python3 -m http.server 8765` in this directory and visit http://localhost:8765.

## Scope

This prototype supports design feedback. It does not establish real speech recognition, song retrieval accuracy, or driving safety. This repository contains only the demonstration and its audio assets, not participant data or the course report.
